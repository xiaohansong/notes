# Thu 5/21

**TL;DR** rest · last day before test · optional 5-min bar primer if you want to feel the groove

> Final taper day. **Real rest is the right call.** A short bar primer is optional only if you usually feel better having touched the bar within 24 hours of a max — otherwise skip.

## Default — Rest

- Eat well (carbs, water), sleep 8+ hrs.
- Light walk / Z2 only. No bike sprints.
- Active yoga / activation work OK.
- No abductor machine, no heavy anything.

## Optional — 5-minute bar primer (skip if uncertain)

If and only if you've found pre-max primers helpful in the past:

```
bar × 5
135 × 3
185 × 1
225 × 1
DONE.
```

No 275+, no doubles, no "just one more." This is movement opener, not load testing. If you find yourself wanting to add a set, you've already failed the primer's purpose — bail and walk away.

## What NOT to do

- No make-up lifting.
- No "test the 395 today to see how it feels." That's the failure mode.
- No new modalities, no novel movements.
- No heavy abductor / glute machine work.
