## Pre-session decision (before walking up)

Decide before warm-ups: **350×3** is the default open, **340×3** is the bail-down if conditions are off. Don't walk in and let the bar tell you. Pick now.

Drop to 340 if: sleep was bad, RDL Tue felt grindy, warm-up squats feel off. A clean 340×3 still beats a missed 350.

## 1. Back Squat — Top Heavy Triple

```
1 working triple
3 reps @ 350#  (target RPE 9)
```

**Bail rules — preset, not in-the-moment:**
- Rep 1 RPE 9+ → drop the bar, re-attempt 340×3 after 4 min rest. Banked 340 = a productive day.
- Rep 2 hesitates or grinds → bail. Hesitation = bail rule applies. Don't try rep 3 to "see if it's there."
- Reps 1 and 2 fly → finish rep 3 with full intent. Clean rep 3 = the new 3RM at 350.

Belt and shoes on. 4–6 min rest after the last warm-up single. 5/8's 345×3 went 8.5/10 RPE — 350 is a real but not stretch jump.

**Decision rule (next heavy day, 5/22):** clean 350×3 (RPE ≤ 9) → target 355×3. Grindy (RPE 9.5) → repeat 350. Bailed → repeat 350 with proper rest.

## 2. Back Squat — Hypertrophy Back-off

```
4 sets, ~3 min rest
5 reps @ 295#  (78%)
```

Quality-rep back-offs, not a second hard session. Same brace, same depth, smooth tempo. If 295# moves like air across all 4 sets, next heavy day's back-off can go to 300#.

If the heavy triple bailed or grinded badly, drop to 3 sets here and call it a day — don't compound the CNS hit.

## 3. Bulgarian Split Squat — Single-Leg Hypertrophy

```
4 sets, every 2:30
8 reps each side @ 35–40# DBs (each hand)
```

Different stimulus from 5/8's weighted step-ups (which went well — 5×14 @ 44#/hand, only the 4th set tagged as "cardio gone"). BSS is more strength-biased than the step-up's metabolic cadence — slower descent, longer time under tension on the working leg.

5/1 was BSS @ 35# 8/side RPE 7. Bump to 40# this week; if 40# is RPE 9 by set 2, drop back to 35#. Rear foot elevated, vertical torso, drive through front-foot heel. Don't bounce out of the bottom.

If the heavy triple genuinely cooked you, you can skip this. But the BSS is a meaningful hypertrophy hit, not filler — only skip if you'd skip back-offs too.

## 4. Good Morning (or GHD Back Extension) — Anti-flexion Core

```
3 sets × 10 reps, NFT
Empty bar (45#) or 65# / BW on GHD
```

Posterior, light, anti-flexion — this bucket is at ~7 sets in the 28-day window, under the ~3/wk maintenance target. Different stimulus from squat (no spinal compression), complements the heavy triple recovery curve.

Hinge at the hips, neutral spine, squeeze glutes at top — no overextension. If you don't have a GHD, sub good morning at empty bar (45#) or 65# for 10 reps.
