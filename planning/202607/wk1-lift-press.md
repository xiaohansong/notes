# Press day — wk 1

**TL;DR**

- Strict press 5×5 @ 120#, E2:30–3:00 — cycle ladder starts here; all sets ≤ RPE 8 → 122.5# next press day
- Deadlift 3×5 @ 120kg — speed work, crisp off the floor
- Superset: single-arm DB press 3×8/side @ 40# + single-arm DB row 3×8/side @ 70#
- Pallof press 3×10/side @ 55#

## Warm-up (~8 min)

- 3 min easy bike or row
- Band pull-aparts 2×15 + pass-throughs 2×10
- Glute-med activation, light grade: light-band lateral walk 2×10 steps/direction + single-leg glute bridge 2×8/side, left side first. Priming, not training — no burn-chasing, this is not Friday's loaded block.
- Press ramp: bar × 10, 75 × 5, 95 × 3, 110 × 2 → working sets
- Before the DL fives later: 60kg × 5, 90 × 3, 110 × 1 — quick, no grinding

## Strict press — 5×5 @ 120#, E2:30–3:00

Run solo. Gate for +2.5#: all 25 reps at RPE ≤ 8. A missed rep = hold next week, nothing else changes. Reference: 121# was RPE 7 across (5/5), 125# dropped a rep (5/13) — 120 should be a clean opener.

## Deadlift — 3×5 @ 120kg

~70% of the 7/10 e1RM. Every rep fast off the floor — this slot is bar speed + left-foot-pressure practice, not a workout to survive. If speed dies mid-set, end the set.

## Accessory superset — 3 rounds

- Single-arm DB press × 8/side @ 40#
- Single-arm DB row × 8/side @ 70#

Reference (5/13): press went 40 × 8/9/8 — gate to 45# is all three sets at a clean 8/side. Row went 70 × 6/6/7 — build to 3×8/side at 70 before 75#. Log reps per side.

## Pallof press — 3×10/side @ 55#

Slow, square hips. Gate: 3×12/side clean → +5#.

## What NOT to do

- No pushing 120 to a 6th rep "because it moved well" — the gate is clean 5s; the ladder does the progressing.
- No heavy pulls — the DL day owns the heavy hinge slot.
- No conditioning add-on; CrossFit covers it this week.

## Logging

workout/ file for whatever date this runs — note press RPE by set (the +2.5 gate reads it), any DL speed loss, and accessory reps per side (the gates read those too).
