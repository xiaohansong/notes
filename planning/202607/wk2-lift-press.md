# Press day — wk 2

**TL;DR**

- Strict press 5×5 @ 120#, E2:30–3:00 — ladder opener, carried over unchanged from wk 1 (it never ran)
- Deadlift 3×5 @ 120kg (265#) — speed work, crisp off the floor
- Superset: single-arm DB press 3×8/side @ 40# + single-arm DB row 3×8/side @ 70#
- Pallof press 3×10/side @ 55#

> **This is the week's first-priority slot — schedule it first and let everything else flex around it.** Wk 1 ran six sessions but this one got displaced by a third CrossFit day, so the cycle's featured ladder hasn't started, and the week's only rowing and anti-rotation work vanished with it. The cycle rule is: never skip a heavy slot — the CrossFit days are the flex pieces, not the barbell days.

## Warm-up (~8 min)

- 3 min easy bike or row
- Band pull-aparts 2×15 + pass-throughs 2×10
- Glute-med activation, light grade: light-band lateral walk 2×10 steps/direction + single-leg glute bridge 2×8/side, left side first
- Press ramp: bar × 10, 75 × 5, 95 × 3, 110 × 2 → working sets
- Before the DL fives later: 60kg × 5, 90 × 3, 110 × 1 — quick, no grinding

## Strict press — 5×5 @ 120#, E2:30–3:00

Run solo. Gate for +2.5#: all 25 reps at RPE ≤ 8. A missed rep = hold next week, nothing else changes.

Don't read anything into 7/14's shaky 4×6 — that was day-after-jerk-WOD fatigue in the technique slot, not a strength change. 120# is still the right opener (121# went RPE 7 across on 5/5). One placement rule: if a choice exists, don't run this day within 24h after an overhead WOD — 7/13 jerks → 7/14 shaking was the live demo. If it lands there anyway, keep the load, expect hot RPE, and read the gate charitably.

## Deadlift — 3×5 @ 120kg (265#)

Speed slot: every rep fast off the floor, left-foot pressure even. If speed dies mid-set, end the set. This load holds while the top-triple ladder climbs — it starts tracking ~70% of the ladder from wk 3.

## Accessory superset — 3 rounds

- Single-arm DB press × 8/side @ 40#
- Single-arm DB row × 8/side @ 70#

Gates unchanged: press → 45# when all three sets hit a clean 8/side (last read 8/9/8 on 5/13); row → build to 3×8/side at 70# first (last read 6/6/7), then 75#. Log reps per side.

## Pallof press — 3×10/side @ 55#

Slow, square hips. Gate: 3×12/side clean → +5#.

## What NOT to do

- No pushing 120 to a 6th rep because it moves well — the gate is clean 5s.
- No heavy pulls — the DL day owns the heavy hinge slot.
- No conditioning add-on; CrossFit covers it.

## Logging

workout/ file for whatever date this runs — press RPE by set (the +2.5 gate reads it), any DL speed loss, accessory reps per side.
