# Run E — wk 2

**TL;DR**

- **40 min easy — live rule: HR under `162`** (alert set; sustained cross → walk it down, resume ~155)
- Whole sentences the whole way; pace is whatever results. Post-run check: avg ≤ 160
- Flex session — slot anywhere the ceiling can hold; Sat morning = bodyweight check day

> 7/18 was the first full-length Run E to pass the audit (avg 157) — the walk-break protocol worked exactly as designed. Same protocol, +8 minutes.

## Notes

Duration is the only thing progressing: 32 → 40 min. The ceilings never move.

One refinement to the 7/18 protocol: resuming at ~155 is enough — walking all the way down to 150 is extra standing around for no extra control. Cross 162 sustained → walk/shuffle → resume around 155.

Pace on 7/18 read 11:58 with walk breaks on a sunny day — that is not a fitness signal, it's weather. No pace floor on this day, ever. The readout that matters (easy pace at the cap, vs the `~11:10 @ 156` baseline) gets taken at CP2 on comparable conditions, not week to week.

Worth saying: the effort discipline that slipped on Run Q held perfectly here. Same skill, same athlete — carry it across.

## What NOT to do

- No riding 165–172 because the legs feel good — that's the steady zone this run exists to stay out of.
- No making up "lost" pace after walk breaks.

## Logging

workout/ file for whatever date this runs — duration, avg pace, **avg HR** (continuous run, so the average means something), walk-break count. Saturday morning: bodyweight, consistent conditions — none logged for wk 1 and the cycle wants the weekly Sat reading (watching the rebound from 177).
