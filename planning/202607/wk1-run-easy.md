# Run E — wk 1

**TL;DR**

- **35 min easy — live rule: HR under `162`** (Garmin high-HR alert at 162; sustained cross → walk to ~155, resume; hill crests to 168 OK)
- Whole sentences the entire way; pace is whatever results. Post-run check: avg ≤ 160
- Flex session: slot it anywhere, day after DL triples included — as long as the ceiling holds

## Warm-up

None needed — first 5 min deliberately slow (HR will read 130s–140s; that's the ramp, not a problem), then settle in under the ceiling.

## Notes

HR + talk test govern this day, not pace and not RPE. Zones are set off Garmin max 200 with the talk test as anchor: whole sentences hold to ~165, so easy = avg ≤ 160 with a small buffer. The 7/11 run (avg 168) sat just above that line — steady, not easy. If talking breaks, slow down regardless of HR. Pace never progresses on this day; duration does (40 min next week). The pace that avg ≤ 160 produces IS the fitness readout: watch it drop over the block at the same cap.

## What NOT to do

- No riding HR 165–172 because the legs feel good — that's the steady zone the 7/11 run lived in, and it taxes recovery while training neither speed nor base. This run's job is to make Run Q productive, not to prove fitness.

## Logging

workout/ file for whatever date this runs — duration, avg pace, **avg HR**. Avg HR > 165 = effort creep, this block's failure mode; log it honestly and it gets called out.
